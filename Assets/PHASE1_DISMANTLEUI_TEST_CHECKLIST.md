# Phase 1: DismantleUI 테스트 체크리스트

## 📋 개요
이 체크리스트는 **DismantleUI**의 모든 기능을 체계적으로 테스트하기 위한 단계별 가이드입니다.

---

## 🎯 테스트 환경 준비

### 사전 준비 사항
- [ ] Unity Editor Play 모드 진입
- [ ] 로비 진입 완료
- [ ] 공방(Workshop) UI 오픈
- [ ] **분해 탭** 활성화
- [ ] Console 창 오픈 (디버그 로그 확인용)

### 테스트 데이터 준비
- [ ] 계정 공유 창고에 **다양한 등급**의 아이템 10개 이상 준비
  - D등급 × 3개
  - C등급 × 3개
  - B등급 × 2개
  - A등급 × 1개
  - S등급 × 1개
- [ ] 강화된 아이템 2개 이상 준비 (+3, +5 등)
- [ ] 귀속된 아이템 1개 이상 준비

## Test 1: 인벤토리 리스트 표시 ✅

### 목적
계정 공유 창고의 아이템들이 제대로 표시되는지 확인

### 테스트 단계
1. 분해 탭 오픈
2. LeftSection의 `InventoryGrid`에 아이템 슬롯들이 표시되는지 확인
3. 각 슬롯이 제대로 렌더링되는지 확인:
   - [ ] 아이템 아이콘 표시
   - [ ] 아이템 이름 표시
   - [ ] 등급 표시 (등급별 색상)
   - [ ] 강화 수치 표시 (+N)
   - [ ] 귀속 아이콘 표시 (귀속 아이템)

### 예상 결과
- ✅ 모든 아이템이 Grid 형태로 정렬
- ✅ 5열 Grid Layout 적용
- ✅ 스크롤 정상 작동

### 검증 로그
```
📦 [DismantleUI] 초기화 시작
🔄 [DismantleUI] 인벤토리 리스트 갱신 시작
📊 [DismantleUI] 계정 공유 창고 아이템 수: XX
✅ [DismantleUI] 분해 가능한 아이템: XX개
✅ [DismantleUI] 초기화 완료
```

## Test 2: 등급 필터링 ✅

### 목적
`minGradeFilter` 설정에 따라 아이템이 필터링되는지 확인

### 테스트 단계
1. **Play 모드 중지**
2. `DismantleSubPanel` 선택 → `DismantleUI` 컴포넌트
3. `Min Grade Filter` 변경:
   - **Case A**: D등급 (기본값) → 모든 아이템 표시
   - **Case B**: B등급 → B/A/S등급만 표시
   - **Case C**: A등급 → A/S등급만 표시
4. Play 모드 재진입 → 분해 탭 확인

### 예상 결과
- ✅ Case A: D/C/B/A/S 모두 표시
- ✅ Case B: B/A/S만 표시 (D/C 제외)
- ✅ Case C: A/S만 표시 (D/C/B 제외)

## Test 4: B안 - 대표 슬롯 + 개수 표시 ✅

### 목적
선택된 아이템 요약이 제대로 표시되는지 확인 (B안)

### 테스트 단계
1. 아이템 **1개** 선택
   - [ ] `SelectedItemSummary` 활성화
   - [ ] `RepresentativeSlot`에 선택된 아이템 표시
   - [ ] `CountText` 비어있음 (또는 비표시)
2. 아이템 **5개** 추가 선택 (총 6개)
   - [ ] `RepresentativeSlot`에 첫 번째 아이템 표시
   - [ ] `CountText`: "외 5개"
3. 아이템 **10개** 추가 선택 (총 16개)
   - [ ] `RepresentativeSlot`: 첫 번째 아이템
   - [ ] `CountText`: "외 15개"
4. 모든 선택 해제
   - [ ] `SelectedItemSummary` 비활성화

### 예상 결과
- ✅ 선택 개수에 따라 `CountText` 자동 업데이트
- ✅ 대표 슬롯은 항상 첫 번째 선택 아이템
- ✅ 선택 0개 시 전체 영역 비활성화

### 검증 로그
```
📊 [DismantleUI] B안 표시 - 대표: {아이템명}, 총 X개
```

## Test 5: 보상 미리보기 - 자동 크기 조절 ✅

### 목적
선택된 아이템에 따라 보상 재료가 표시되고, 재료 개수에 따라 슬롯 크기가 자동 조절되는지 확인

### 테스트 단계

#### Case A: 재료 3개 이하 (큰 슬롯 150px)
1. D등급 아이템 3개 선택 (예상 재료: 2~3종류)
2. `RewardPreview` 활성화 확인
3. `RewardSlotsContainer`의 슬롯 크기 확인
   - [ ] 슬롯 크기: 150px × 150px
   - [ ] 재료 아이콘 큼
   - [ ] 재료 개수 텍스트 명확

#### Case B: 재료 4~6개 (작은 슬롯 75px)
1. 다양한 등급 아이템 10개 선택 (예상 재료: 5종류)
2. 슬롯 크기 변경 확인
   - [ ] 슬롯 크기: 75px × 75px
   - [ ] 재료 아이콘 중간 크기
   - [ ] 가독성 유지

#### Case C: 재료 7~9개 (최소 슬롯 60px)
1. 모든 등급 혼합 아이템 20개 선택 (예상 재료: 9종류)
2. 슬롯 크기 최소화 확인
   - [ ] 슬롯 크기: 60px × 60px
   - [ ] 재료 아이콘 작음
   - [ ] 모든 재료 한 줄에 표시

### 예상 결과
- ✅ 재료 개수에 따라 슬롯 크기 자동 조절
- ✅ HorizontalLayoutGroup 중앙 정렬
- ✅ 모든 재료 슬롯 정상 표시

### 검증 로그
```
💎 [DismantleUI] 보상 계산 완료 - 재료 종류: X개
📏 [DismantleUI] 슬롯 크기: XXXpx (재료 X종류)
🔍 [DismantleUI] rewardPreview 활성화 → 1프레임 대기 후 슬롯 설정
⏰ [DismantleUI] 1프레임 대기 완료 → 보상 슬롯 생성 시작
📦 [DismantleUI] 재료 슬롯 설정 완료: {재료타입} x{개수}
✅ [DismantleUI] 보상 슬롯 X개 생성 완료
```

## Test 6: 재료 슬롯 표시 정상 작동 ✅ (Phase 0의 교훈)

### 목적
재료 슬롯의 아이콘이 제대로 표시되는지 확인 (2-stage delay)

### 테스트 단계
1. 아이템 5개 선택 → 보상 미리보기 확인
2. 각 재료 슬롯 확인:
   - [ ] 재료 아이콘 표시됨 ⭐
   - [ ] 재료 개수 텍스트 표시됨
   - [ ] 배경 이미지 표시됨
3. 다른 아이템 조합 선택 → 보상 갱신 확인
4. 슬롯이 깜빡이거나 사라지지 않는지 확인

### 예상 결과
- ✅ **모든 재료 슬롯 아이콘 정상 표시** (Phase 0 버그 해결)
- ✅ `rewardPreview` 활성화 후 1프레임 대기
- ✅ `Instantiate()` 후 1프레임 대기

### 검증 로그
```
🔍 [DismantleUI] rewardPreview 활성화 → 1프레임 대기 후 슬롯 설정
⏰ [DismantleUI] 1프레임 대기 완료 → 보상 슬롯 생성 시작
📦 [DismantleUI] 재료 슬롯 설정 완료: {재료} x{개수}
```

## Test 9: 확인 팝업 표시 ✅

ConfirmationPopup이 제대로 표시되고 정보가 정확한지 확인

### 테스트 단계
1. 아이템 5개 선택 (다양한 등급)
2. **분해하기 버튼** 클릭
3. `ConfirmationPopup` 확인:
   - [ ] 제목: "아이템 분해"
   - [ ] 메시지: "선택한 5개의 아이템을 분해하시겠습니까?"
   - [ ] 상세 정보:
     - [ ] "획득 가능 재료:" 목록 표시
     - [ ] 재료 타입별 개수 정확
     - [ ] "※ 분해된 아이템은 복구할 수 없습니다." 경고 표시
   - [ ] 확인/취소 버튼 표시
4. **취소 버튼** 클릭 → 팝업 닫힘, 선택 유지

### 예상 결과
- ✅ 팝업 정상 표시
- ✅ 보상 정보 정확
- ✅ 취소 시 선택 유지

```

## Test 10: 분해 실행 및 결과 피드백 ✅

### 목적
실제 분해가 정상적으로 실행되고 결과가 표시되는지 확인

### 테스트 단계
1. 아이템 3개 선택 (예: D등급 × 2, C등급 × 1)
2. **분해하기 버튼** 클릭
3. `ConfirmationPopup`에서 **확인 버튼** 클릭
4. `ResultFeedbackPopup` 확인:
   - [ ] "분해 완료!" 제목
   - [ ] "3개 아이템 분해" 메시지
   - [ ] 획득한 재료 목록 표시
   - [ ] 재료 슬롯 아이콘 정상 표시
   - [ ] 재료 개수 정확
5. **확인 버튼** 클릭 → 팝업 닫힘
6. UI 상태 확인:
   - [ ] 선택 초기화 (선택 0개)
   - [ ] 인벤토리 리스트 갱신 (분해된 아이템 제거)
   - [ ] 계정 공유 창고에 재료 추가 (다른 UI에서 확인)

### 예상 결과
- ✅ 분해 성공
- ✅ 결과 팝업 정상 표시
- ✅ 인벤토리 자동 갱신
- ✅ 재료 획득 반영

### 검증 로그
```
⚙️ [DismantleUI] 분해 실행 시작 - X개
✅ [DismantleUI] 분해 성공 - 재료 X종류 획득
🔄 [DismantleUI] 인벤토리 리스트 갱신 시작
✅ [DismantleUI] 분해 가능한 아이템: XX개

## 📌 참고: 자주 발생하는 문제

### 문제 1: 재료 슬롯 아이콘이 보이지 않음

**원인**: Layout Group 버그 (Phase 0의 교훈)

**해결**: 2-stage delay 시스템이 적용되어 있는지 확인
```csharp
// rewardPreview 활성화 후 1프레임 대기
if (!rewardPreview.activeSelf) {
    rewardPreview.SetActive(true);
    StartCoroutine(UpdateRewardPreviewDelayed(...));
    return;
}

// Instantiate 후 1프레임 대기
StartCoroutine(SetupMaterialSlotDelayed(...));
```

### 문제 2: 슬롯 크기가 변하지 않음

**원인**: HorizontalLayoutGroup의 `Child Control Size` 체크됨

**해결**: Inspector에서 `Child Control Size` 모두 해제

### 문제 3: 보상 계산이 부정확함

**원인**: DismantleSystem의 로직 문제

**해결**: `DismantleSystem.CalculateTotalRewards()` 로직 확인
