## 🎯 **핵심 포인트**

### **1. 스탯 증가율 (레벨별)**

#### **초급 구간 (Lv 1~5):**
- 무기: +1.5% / 레벨
- 방어구: +1.2% / 레벨
- 악세서리: +0.8% / 레벨

#### **중급 구간 (Lv 6~10):**
- 무기: +2.0% / 레벨
- 방어구: +1.6% / 레벨
- 악세서리: +1.0% / 레벨

#### **고급 구간 (Lv 11~15):**
- 무기: +3.0% / 레벨
- 방어구: +2.4% / 레벨
- 악세서리: +1.5% / 레벨

## 🔧 **Unity Inspector 설정 가이드**

### **Step 1: EnhancementData 생성**

1. **Project 창** → `Assets/Resources/Data/` 폴더

2. **우클릭** → **Create → Data → Enhancement Data**

3. **이름**: `EnhancementData`

### **Step 2: 레벨별 데이터 입력**

1. **EnhancementData** Asset 선택

2. **Inspector 창** → **Level Table** 섹션

3. **Size**: 16 (Lv 0~15)

4. **각 레벨별로 입력**:

#### **예시 (Lv 1):**
```
Level Table
  └─ Element 1
      Level: 1
      Gold Cost: 200
      Material Count: 1
      Success Rate: 0.95
      Stat Rate Add Weapon: 1.5
      Stat Rate Add Armor: 1.2
      Stat Rate Add Accessory: 0.8
      Bonus Id: (비워둠)
      Bonus Description: (비워둠)
```

#### **예시 (Lv 3 - 보너스 포함):**
```
Level Table
  └─ Element 3
      Level: 3
      Gold Cost: 550
      Material Count: 2
      Success Rate: 0.88
      Stat Rate Add Weapon: 1.5
      Stat Rate Add Armor: 1.2
      Stat Rate Add Accessory: 0.8
      Bonus Id: BONUS_LV3
      Bonus Description: "크리티컬 확률 +1%"
```

## 📊 **스탯 계산 예시**

### **예시 1: 공격력 100인 무기를 +5 강화**

```
기본 공격력: 100
누적 스탯 보너스: +7.5%
최종 공격력: 100 × (1 + 0.075) = 107.5

### **예시 2: 공격력 100인 무기를 +10 강화**

```
기본 공격력: 100
누적 스탯 보너스: +17.5%
최종 공격력: 100 × (1 + 0.175) = 117.5
```

### **예시 3: 공격력 100인 무기를 +15 강화**

```
기본 공격력: 100
누적 스탯 보너스: +32.5%
최종 공격력: 100 × (1 + 0.325) = 132.5

## 🎯 **밸런스 조정 가이드**

### **스탯 증가율 조정**

#### **더 쉽게 (스탯 증가량 UP):**
```
초급 구간: 1.5% → 2.0%
중급 구간: 2.0% → 2.5%
고급 구간: 3.0% → 4.0%
```

#### **더 어렵게 (스탯 증가량 DOWN):**
```
초급 구간: 1.5% → 1.0%
중급 구간: 2.0% → 1.5%
고급 구간: 3.0% → 2.0%
```

### **성공률 조정**

#### **더 쉽게:**
```
전체 성공률 +10%
(예: Lv 10: 58% → 68%)
```

#### **더 어렵게:**
```
전체 성공률 -10%
(예: Lv 10: 58% → 48%)
```

### **비용 조정**

#### **골드 부족 시:**
```
전체 골드 ×0.7
(예: Lv 10: 4,100G → 2,870G)
```

#### **재료 부족 시:**
```
전체 재료 개수 -1
(예: Lv 10: 5개 → 4개)
```
