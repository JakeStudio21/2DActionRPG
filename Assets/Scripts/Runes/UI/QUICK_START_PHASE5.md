## 🎮 씬 실행 테스트 (필수 체크)

### 체크리스트

1. **인벤토리**
   - [ ] 룬 목록 표시
   - [ ] 룬 클릭 시 툴팁 표시

2. **툴팁**
   - [ ] 주옵션 스케일링 수치 표시 (예: Lv.1 = 20%, Lv.10 = 34%)
   - [ ] 부옵션 목록 표시
   - [ ] 빈 슬롯 안내 문구

3. **드래그 앤 드롭**
   - [ ] 인벤토리 → 장착 슬롯 드래그
   - [ ] 드롭 시 장착 성공
   - [ ] 중복 장착 시 에러 메시지

4. **장착 해제**
   - [ ] 우클릭/더블클릭 시 해제
   - [ ] 인벤토리 상태 갱신

5. **레벨업**
   - [ ] 스탯 비교 표시 (20% → 21%)
   - [ ] [강화] 버튼 클릭 시 레벨업
   - [ ] 최대 레벨 도달 시 버튼 비활성화

6. **한계돌파**
   - [ ] 재료 목록 필터링 (동일 runeId, Lv.1)
   - [ ] [한계돌파] 버튼 클릭 시 한계돌파
   - [ ] 5한돌 완료 시 "최종 한계돌파 완료" 메시지

## 🛠️ Unity 에디터 최소 설정

### RuneEquipSlot (3개 필요)

1. **빈 GameObject 생성** → `RuneEquipSlot0`
2. **RuneEquipSlotUI** 스크립트 추가
3. **Slot Index** 설정: `0` (나머지는 1, 2)
4. 하위에 **Image** (배경, 아이콘), **TMP** (레벨), **5개 별** 추가
5. SerializeField 연결

### RuneEnhancePanel

1. **빈 GameObject 생성** → `RuneEnhancePanel`
2. **RuneEnhanceUI** 스크립트 추가
3. 하위에 **탭 버튼**, **정보 텍스트**, **강화 버튼** 추가
4. SerializeField 연결

**상세 설정은 `Phase5-2_Setup_Guide.md` 참조**
