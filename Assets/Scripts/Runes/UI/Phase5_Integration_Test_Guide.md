## 🐛 알려진 이슈 및 해결

### Issue 1: 드롭이 작동하지 않음

**원인**: `CanvasGroup.blocksRaycasts`가 true로 유지됨

**해결**:
- `RuneDragHandler.OnBeginDrag()`에서 자동으로 `false`로 설정
- `OnEndDrag()`에서 `true`로 복구

---

### Issue 2: 재료 목록이 비어있음

**원인**: 동일 `runeId`의 Lv.1 룬이 없음

**해결**:
- 에디터 메뉴: `Phase 5-2/4. 한계돌파 테스트`
- 자동으로 재료 룬 생성

---

### Issue 3: 에러 메시지가 사라지지 않음

**원인**: `errorMessageTimer` 업데이트 누락

**해결**:
- `RuneEquipSlotUI.Update()`에서 타이머 감소 처리
- 2초 후 자동으로 숨김
