## 🎯 테스트 준비

### 1단계: 테스트 데이터 생성

**에디터 메뉴 실행:**
```
Unity 상단 메뉴 > Runes > Phase 5 - UI > Phase 5-2/5. 풀 시나리오 테스트
```

**예상 결과:**
- 콘솔에 "✅ Phase 5-2 풀 시나리오 테스트 완료!" 메시지
- 총 룬 개수: 4개
- 장착된 룬: 1개

### 2단계: Lobby 씬 실행

1. `Assets/Scenes/Lobby.unity` 열기
2. Unity 에디터에서 **플레이 버튼(▶)** 클릭
3. 게임 화면이 정상 실행되는지 확인

### 3단계: 룬 UI 열기

**방법 1: UI 버튼 클릭**
- 화면에서 "룬" 또는 "Runes" 버튼 찾기
- 버튼 클릭하여 룬 인벤토리 패널 열기

**방법 2: 직접 활성화 (버튼이 없는 경우)**
1. 하이어라키에서 `RuneInventoryPanel` 찾기
2. Inspector에서 체크박스 활성화

**확인 사항:**
- ✅ 룬 인벤토리 패널이 화면에 나타남
- ✅ 4개의 룬 슬롯이 보임
- ✅ 각 슬롯에 룬 아이콘, 이름, 레벨이 표시됨

## 🖱️ 드래그 앤 드롭 테스트

### 테스트 1: 기본 드래그 앤 드롭

#### 1.1 룬 드래그 시작
1. 인벤토리에서 **"방어 파괴자 Lv.1"** 룬 찾기
2. 마우스 왼쪽 버튼으로 **클릭 & 홀드**
3. 마우스를 움직이기

**예상 결과:**
- ✅ 원본 룬 슬롯이 **반투명(alpha 0.3)**으로 변함
- ✅ 마우스 커서를 따라다니는 **임시 아이콘**이 나타남
- ✅ 임시 아이콘은 약간 투명(alpha 0.6)하고 크기 100x100

#### 1.2 장착 슬롯으로 드롭
1. 마우스를 **빈 장착 슬롯(RuneEquipSlot1 또는 2)**으로 이동
2. 마우스 버튼을 **놓기(Release)**

**예상 결과:**
- ✅ 원본 룬 슬롯이 정상 불투명도로 복구
- ✅ 임시 아이콘 사라짐
- ✅ 장착 슬롯에 룬 정보가 표시됨:
  - 룬 아이콘
  - 레벨 텍스트 "Lv.1"
  - 룬 이름
  - 한계돌파 별 (회색 5개)

#### 1.3 콘솔 로그 확인
```
[RuneManager] 룬 장착: [방어 파괴자] Lv.1 (한돌 0) | 부옵션 0개 → 슬롯 1
[RuneManager] 활성 조건부 모디파이어: 1개 (레벨 보정 적용)
[PlayerRuntimeStats] 조건부 모디파이어 설정: 1개
[RuneManager] PlayerRuntimeStats에 1개 조건부 모디파이어 전달
```

### 테스트 2: 중복 장착 방지

#### 2.1 동일 룬 다시 드래그
1. 인벤토리에서 **이미 장착한 "방어 파괴자 Lv.1"** 룬 다시 드래그
2. **다른 빈 슬롯**에 드롭 시도

**예상 결과:**
- ✅ 장착 슬롯에 **빨간색 에러 메시지** 표시:
  ```
  "동일한 룬은 장착할 수 없습니다"
  ```
- ✅ 메시지는 **2초 후 자동으로 사라짐**
- ✅ 룬은 장착되지 않고 인벤토리에 그대로 유지

#### 2.2 콘솔 로그 확인
```
[RuneEquipSlotUI] 드롭 실패: 이미 장착된 룬입니다 (UID: xxxxx)
```

### 테스트 3: 전체 슬롯 장착

1. **"고체력 사냥꾼 Lv.1"** 룬을 빈 슬롯에 드래그 앤 드롭
2. 3개 슬롯 모두 채워지는지 확인

**예상 결과:**
- ✅ 슬롯 0: "보스 사냥꾼 Lv.4" (한계돌파 +0)
- ✅ 슬롯 1: "방어 파괴자 Lv.1"
- ✅ 슬롯 2: "고체력 사냥꾼 Lv.1"

---

### 테스트 4: 장착 해제 (우클릭)

#### 4.1 우클릭으로 해제
1. **슬롯 1 (방어 파괴자)** 위에 마우스 커서 올리기
2. **마우스 오른쪽 버튼 클릭**

**예상 결과:**
- ✅ 슬롯이 비워짐
- ✅ "빈 슬롯" 표시가 나타남
- ✅ 룸 인벤토리에 "방어 파괴자 Lv.1" 다시 표시됨

#### 4.2 콘솔 로그 확인
```
[RuneManager] 룬 해제: [방어 파괴자] Lv.1 (한돌 0) | 부옵션 0개 ← 슬롯 1
[RuneManager] 활성 조건부 모디파이어: 2개 (레벨 보정 적용)
[PlayerRuntimeStats] 조건부 모디파이어 설정: 2개
[RuneManager] PlayerRuntimeStats에 2개 조건부 모디파이어 전달
```

---

### 테스트 5: 장착 해제 (더블클릭)

#### 5.1 더블클릭으로 해제
1. **슬롯 2 (고체력 사냥꾼)** 위에 마우스 커서 올리기
2. **마우스 왼쪽 버튼 빠르게 2번 클릭**

**예상 결과:**
- ✅ 슬롯이 비워짐
- ✅ 인벤토리에 룬 복귀

**비교:**
- 우클릭: 1회 클릭으로 즉시 해제
- 더블클릭: 0.3초 이내 2회 클릭 필요

## 📈 레벨업 UI 테스트

### 테스트 6: 강화 UI 열기

#### 6.1 룬 선택
1. 인벤토리에서 **"방어 파괴자 Lv.1"** 룬 **왼쪽 클릭**
2. 강화 UI 패널(`RuneEnhancePanel`)이 자동으로 나타나는지 확인

**예상 결과:**
- ✅ 강화 UI 패널이 활성화됨
- ✅ 상단에 선택한 룬 정보 표시:
  - 룬 아이콘
  - "방어 파괴자" (이름)
  - "Lv.1 (한계돌파 +0)" (현재 레벨)

#### 6.2 레벨업 탭 확인
- ✅ **"레벨업"** 탭이 기본 활성화됨
- ✅ 탭 버튼 색상이 다르게 표시됨 (선택된 상태)

---

### 테스트 7: 스탯 미리보기

#### 7.1 현재/다음 스탯 표시
강화 UI에서 다음 내용이 표시되는지 확인:

```
[현재 스탯]
방어 무시 10%

→

[다음 스탯]
방어 무시 11%
```

**확인 사항:**
- ✅ 현재 스탯 텍스트가 정확함
- ✅ 화살표(→) 표시됨
- ✅ 다음 레벨 스탯 미리보기 표시됨
- ✅ 스탯 수치가 정확하게 계산됨 (baseValue + levelValue × currentLevel)

---

### 테스트 8: 레벨업 실행

#### 8.1 강화 버튼 클릭
1. 강화 UI에서 **[강화]** 버튼 클릭
2. 버튼 아래 메시지 확인

**예상 결과 (성공):**
- ✅ "✅ 레벨업 성공! Lv.1 → Lv.2" 메시지
- ✅ 메시지 색상: **초록색**
- ✅ 현재 레벨 텍스트 업데이트: "Lv.2 (한계돌파 +0)"
- ✅ 스탯 미리보기 갱신:
  ```
  방어 무시 11% → 방어 무시 12%
  ```

#### 8.2 연속 레벨업
1. [강화] 버튼 2번 더 클릭
2. Lv.2 → Lv.3 → Lv.4로 증가 확인

**Lv.3 특수 효과 확인:**
- ✅ "🎲 부옵션 추첨 성공!" 메시지
- ✅ 부옵션이 랜덤으로 추가됨
- ✅ 툴팁에서 부옵션 확인 가능

#### 8.3 콘솔 로그 확인
```
[RuneEnhanceManager] 레벨업 시도: xxxxx
  대상 룬: [방어 파괴자] Lv.1 (한돌 0) | 부옵션 0개
[RuneEnhanceManager] ✅ 레벨업 성공: Lv.1 → Lv.2
```

---

### 테스트 9: 최대 레벨 도달

#### 9.1 레벨 10까지 올리기
1. [강화] 버튼을 **9번** 클릭 (Lv.1 → Lv.10)
2. 각 마일스톤(Lv.3, 6, 9)에서 부옵션 추첨 메시지 확인

#### 9.2 최대 레벨 도달 시
**예상 결과:**
- ✅ [강화] 버튼 **비활성화**됨 (Interactable = false)
- ✅ 버튼 텍스트: "최대 레벨 도달"
- ✅ 스탯 미리보기 숨겨짐 (화살표 없음)
- ✅ 메시지: "⚠️ 최대 레벨입니다. 한계돌파를 진행해주세요."

### 테스트 12: 재료 룬 목록

한계돌파 패널 중간에 "재료 선택" 영역 확인:

**예상 결과 (재료가 없는 경우):**
- ✅ "한계돌파 재료가 없습니다" 메시지
- ✅ 빈 스크롤뷰

**재료 생성 (필요 시):**
```
Unity 메뉴 > Runes > Phase 5 - UI > Phase 5-2/4. 한계돌파 테스트
```

#### 12.2 재료 표시 확인
**예상 결과 (재료가 있는 경우):**
- ✅ 동일한 `runeId`의 Lv.1 룬만 표시됨
- ✅ 다른 종류의 룬은 표시되지 않음
- ✅ 재료 슬롯에 룬 아이콘, 이름, 레벨 표시

**예시:**
- 베이스: "방어 파괴자 Lv.10"
- 재료 목록: "방어 파괴자 Lv.1" ✅
- 표시 안 됨: "보스 사냥꾼 Lv.1" ❌

### 테스트 14: 한계돌파 실행

#### 14.1 한계돌파 버튼 클릭
1. [한계돌파] 버튼 클릭
2. 결과 메시지 확인

**예상 결과:**
- ✅ "✅ 한계돌파 성공! +1 (최대 레벨: 11)" 메시지
- ✅ 메시지 색상: **초록색**
- ✅ 상단 정보 갱신:
  ```
  현재 최대 레벨: 11
  한계돌파: 1 / 5
  ```
- ✅ 재료 룬이 인벤토리에서 **사라짐** (소모됨)
- ✅ 재료 목록에서도 제거됨

#### 14.2 장착 슬롯 별 표시
장착 슬롯에서 한계돌파 별 확인:
- ✅ **첫 번째 별**이 **노란색**으로 활성화
- ✅ 나머지 4개는 **회색** 유지

#### 14.3 콘솔 로그 확인
```
[RuneEnhanceManager] 한계돌파 시도
  베이스 룬: xxxxx
  재료 룬: yyyyy
  베이스: [방어 파괴자] Lv.10 (한돌 0) | 부옵션 3개
  재료: [방어 파괴자] Lv.1 (한돌 0) | 부옵션 0개
[RuneEnhanceManager] ✅ 한계돌파 성공!
  한계돌파: 0 → 1
  최대 레벨: Lv.10 → Lv.11
[RuneInventoryManager] 룬 삭제: [방어 파괴자] Lv.1 (한돌 0) | 부옵션 0개 | 남은 룬: N개
```

## 🎬 통합 시나리오 테스트

### 시나리오 1: 신규 룬 완전 육성

**목표:** Lv.1 룬을 Lv.15 (한계돌파 +5)까지 육성

#### 단계별 진행

**1. 준비 (에디터 메뉴)**
```
Runes > Phase 5 - UI > Phase 5-2/1. 데이터 클리어
Runes > Phase 5 - UI > Phase 5-2/4. 한계돌파 테스트
```

**2. 플레이 모드 시작**
- Lobby 씬 실행
- 룬 UI 열기

**3. 초기 육성 (Lv.1 → Lv.10)**
1. "보스 사냥꾼 Lv.1" 선택
2. 강화 UI에서 [강화] 버튼 9번 클릭
3. 각 마일스톤(Lv.3, 6, 9) 부옵션 확인

**4. 첫 번째 한계돌파 (Lv.10 → 최대 Lv.11)**
1. [한계돌파] 탭 클릭
2. 재료 목록에서 "보스 사냥꾼 Lv.1" 선택
3. [한계돌파] 버튼 클릭
4. 성공 메시지 확인
5. 별 1개 활성화 확인

**5. 추가 레벨업 (Lv.10 → Lv.11)**
1. [레벨업] 탭 클릭
2. [강화] 버튼 1번 클릭
3. Lv.11 도달 확인

**6. 반복 (Lv.15까지)**
- 한계돌파 → 레벨업 반복
- 최종: Lv.15 (한계돌파 +5)
- 별 5개 모두 활성화 확인

**최종 확인 사항:**
- ✅ 현재 레벨: Lv.15
- ✅ 한계돌파: 5 / 5
- ✅ 별 5개 모두 노란색
- ✅ 최대 레벨: 15
- ✅ 부옵션 3개 (Lv.3, 6, 9에서 획득)

### 시나리오 2: 3슬롯 동시 운용

**목표:** 3개의 서로 다른 룬을 장착하고 각각 강화

#### 단계별 진행

**1. 장착**
1. "보스 사냥꾼" → 슬롯 0
2. "방어 파괴자" → 슬롯 1
3. "고체력 사냥꾼" → 슬롯 2

**2. 순차 강화**
1. 슬롯 0 룬 선택 → Lv.3까지 강화
2. 슬롯 1 룬 선택 → Lv.3까지 강화
3. 슬롯 2 룬 선택 → Lv.3까지 강화

**3. 효과 확인**
- 3개 룬의 조건부 모디파이어가 모두 활성화되는지 확인
- 콘솔 로그: "조건부 모디파이어 설정: 3개"

**4. 장착 해제**
1. 슬롯 1 우클릭 → 해제
2. 콘솔 로그: "조건부 모디파이어 설정: 2개"
3. 인벤토리에 룬 복귀 확인

**5. 재장착**
1. 인벤토리에서 다시 드래그 앤 드롭
2. 슬롯 1에 재장착
3. 레벨과 부옵션이 **유지**되는지 확인

**최종 확인 사항:**
- ✅ 3개 슬롯 모두 장착됨
- ✅ 각 룬이 Lv.3 이상
- ✅ 조건부 모디파이어 3개 활성화
- ✅ 장착 해제 후 재장착 시 데이터 유지

### 시나리오 3: 에러 케이스 검증

**목표:** 예외 상황에서 올바른 에러 메시지 표시

#### 테스트 케이스

**1. 중복 장착 시도**
- 동일 룬을 다른 슬롯에 드롭
- 예상: "동일한 룬은 장착할 수 없습니다"

**2. 재료 없이 한계돌파 시도**
1. 최대 레벨 룬 선택
2. [한계돌파] 탭 클릭
3. 재료 선택 없이 [한계돌파] 버튼 클릭
- 예상: "재료를 선택해주세요" 메시지

**3. 최대 한계돌파 도달**
1. 룬을 한계돌파 +5까지 진행
2. [한계돌파] 탭 확인
- 예상: [한계돌파] 버튼 비활성화
- 예상: "최대 한계돌파 도달" 메시지

**4. 잘못된 재료 사용 시도**
- 다른 종류의 룬을 재료로 선택
- 예상: 재료 목록에 표시되지 않아야 함

## 🐛 예상 문제 및 해결

### 문제 1: 드래그가 작동하지 않음

**증상:**
- 룬을 드래그해도 아무 반응 없음
- 임시 아이콘이 나타나지 않음

**확인 사항:**
1. `RuneSlotPrefab`에 `RuneDragHandler` 컴포넌트 추가되어 있는지 확인
2. `RuneDragHandler`의 `dragParent` 필드에 Canvas 연결되어 있는지 확인
3. `RuneSlotPrefab`에 `CanvasGroup` 컴포넌트 존재 확인

**해결:**
```
1. RuneSlotPrefab 선택
2. Inspector에서 RuneDragHandler 확인
3. Drag Parent 필드에 최상위 Canvas 드래그
```

---

### 문제 2: 드롭 시 장착되지 않음

**증상:**
- 드래그는 되지만 드롭 시 아무 일도 일어나지 않음

**확인 사항:**
1. `RuneEquipSlotUI` 컴포넌트가 장착 슬롯에 추가되어 있는지 확인
2. `slotIndex`가 올바르게 설정되어 있는지 확인 (0, 1, 2)
3. `EventSystem`이 씬에 존재하는지 확인

**해결:**
```
1. 하이어라키에서 EventSystem 검색
2. 없으면 GameObject > UI > Event System 생성
3. RuneEquipSlotUI의 slotIndex 확인
```

---

### 문제 3: 툴팁이 표시되지 않음

**증상:**
- 마우스를 올려도 툴팁이 나타나지 않음

**확인 사항:**
1. `RuneTooltipUI` 컴포넌트가 씬에 존재하는지 확인
2. 툴팁 패널이 Canvas 하위에 있는지 확인
3. 툴팁 패널의 초기 상태가 비활성화되어 있는지 확인

**해결:**
```
1. 하이어라키에서 RuneTooltipPanel 찾기
2. 없으면 프리팹에서 생성
3. Canvas 하위에 배치
4. Inspector에서 체크박스 해제 (초기 비활성화)
```

---

### 문제 4: 재료 목록이 비어있음

**증상:**
- 한계돌파 탭에서 "재료가 없습니다" 메시지

**원인:**
- 동일한 `runeId`의 Lv.1 룬이 인벤토리에 없음

**해결:**
```
Unity 메뉴 > Runes > Phase 5 - UI > Phase 5-2/4. 한계돌파 테스트
```
- 자동으로 베이스 룬 + 재료 룬 생성됨

---

### 문제 5: UI 갱신이 되지 않음

**증상:**
- 레벨업 후에도 인벤토리에 이전 레벨이 표시됨

**원인:**
- `RefreshAllUI()` 호출 누락

**확인:**
1. 콘솔 로그에서 레벨업 성공 메시지 확인
2. `RuneEnhanceUI`의 `RefreshAllUI()` 메서드 확인

**임시 해결:**
```
Unity 메뉴 > Runes > Phase 5 - UI > Phase 5-2/3. UI 강제 갱신
```
